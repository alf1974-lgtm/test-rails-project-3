KenKen

Fill every row and column with the digits 1–6, each used exactly once.
Numbers in each bold cage must combine to the target using the given operation.

How to play

  • Click a cell to select it, then type a digit or click the number pad.
  • Each row and column must contain every digit from 1 to 6 exactly once.
  • Cells grouped by a bold border form a cage. The small number and symbol in the top-left corner of each cage show the target value and operation.
  • + the digits must sum to the target.
  • − the two digits must differ by the target.
  • × the digits must multiply to the target.
  • ÷ the two digits must divide to the target.
  • A cage with no operator is a single cell whose value equals the target.
